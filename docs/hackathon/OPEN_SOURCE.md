# Open Source mini challenge

CargoMesh is licensed under [MIT](../../LICENSE). That satisfies the repository's license declaration; it does **not by itself establish** a separate Open Source mini-challenge contribution.

The [official rules](https://amazonappdev2026.devpost.com/rules) require an additional open-source project or contribution to an existing public repository during the hackathon window, alongside the primary project. A branch, fork or pull request may qualify; an unmerged PR can be submitted through its accessible fork. The [organizer clarification](https://amazonappdev2026.devpost.com/forum_topics/45567-questions-about-the-rules) distinguishes the separate contribution from the primary-track repository.

## Required delivery fields

| Field | Current documentary status |
|---|---|
| Contribution URL | Not established by this repository audit |
| Additional project repository URL | Not established |
| Contributor GitHub username | Must identify the actual contributor |
| What changed | Describe the actual reusable feature/fix, not simply CargoMesh being public |
| How it works | Link implementation, reproduction and tests |
| Why it matters | Explain benefit to users/developers beyond this demo |
| Timing/license | Check public contribution date during the event and applicable license |

Do not submit CargoMesh PR #145 or this documentation cleanup as an automatically qualifying external contribution. Do not fabricate a new package or claim upstream acceptance. If the team has an existing additional contribution, verify it and fill these fields in Devpost; otherwise leave this mini challenge pending.

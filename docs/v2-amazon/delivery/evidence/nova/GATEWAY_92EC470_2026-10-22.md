## Separate Web limitation found

The same accepted text without continuous PCM reached ready/textInput but produced no audio/response completion within 55 seconds. The existing browser text-only `start(false,false)` path does not start microphone capture or a silence stream. Therefore publishing the new AWS image alone does not close typed-only Web immersion. See the [reproducible friction report](../../friction-logs/NOVA_TEXT_STREAMING_2026-10-22.md).

The initial local checker also mistakenly omitted sending its auth envelope; its 1008 results were discarded after correcting the checker. They were a test-harness mistake, not an authentication regression in the deployed image. Independent CloudShell and corrected local probes reached ready without changing JWT validation or the secret.

The separate quantity/dimension capture fix is already present in main PR148. It does not supply the missing continuous input for text-only audio. No Web code/configuration was changed during this gateway deployment.

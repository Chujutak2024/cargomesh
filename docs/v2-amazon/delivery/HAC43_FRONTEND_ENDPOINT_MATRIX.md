# HAC-43 — matriz de integración FE y endpoints

Snapshot: 50c12d115dd9b2171d9375acd215593de29e8f34. Generada del registro real `carrierResources` (28 grupos); contrastada con routers/schemas de la base. Fecha: 8 de octubre de 2026.

## Convenciones y aceptación

Todos los paths son del mismo origen y requieren sesión/grants V2. La API decide autorización, scope, versiones y resultados. GET usa no-store y lectura del envelope 2.0; la UI valida tipo y carrierId. Los comandos usan Idempotency-Key conservada únicamente para payload idéntico. Las revisiones usan `{expectedVersion,value}` y los comandos el input nativo vigente. No hay setter genérico de status, edición inventada de oferta ni fallback empresarial.

GET de colección: límite 25 en tablas; hasta 100 en pickers/mapa, con advertencia de subconjunto. Buscar filtra la página recibida. Los paths de filas contienen el identificador de la entidad. Para áreas/lanes, eventos/incidentes de ejecución e historial de incidente se exige seleccionar el parent explícito antes de consultar.

Los tests del cliente/dominio no certifican que cada POST haya persistido. API real local: 401 sin sesión. 403/409/errores se verifican con respuestas sintéticas explícitas y tests, no como grants/RLS reales. Falta smoke autenticado para las 28 colecciones y comandos antes de aceptar HAC-43.

## Coordinación y formulario compartido

- GET /api/v2/freight/requests: directorio paginado del tenant autorizado.
- GET /api/v2/freight/requests/{id}: registro persistido y draftVersion.
- GET /api/v2/freight/requests/{id}/serviceability?expectedDraftVersion={version}: path verificado en el cliente HAC-14 vigente; evaluación correlacionada. El componente consume el mapper actual, no inventa una evaluación.
- Formulario: reutiliza cliente/mapper/contratos de HAC-14. onPersisted solo tras GET de round trip; onEvaluation requiere requestId/draftVersion coincidentes. El directorio, revisión y mapa comparten selección. La edición sin confirmar sigue en memoria del formulario; no es una escritura ni un borrador empresarial alternativo en localStorage.

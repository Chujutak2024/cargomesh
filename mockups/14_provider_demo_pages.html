Herramientas Registradas en document.modelContext
⬡ check_service_coverage
Verifica cobertura de corredor (Callao/Lima → Santiago), modo carretero y coordinación aduanera MIC/DTA.
⬡ check_capacity
Consulta unidades listas en terminal Callao y compatibilidad de peso/volumen para los 10 pallets (8,000 kg).
⬡ quote_freight
Genera cotización formal con desglose de flete base, gestión fronteriza y seguro internacional.
⬡ book_freight
Recibe solicitud de reserva y retorna provider_reference (ej. AND-BOOK-8821) en estado PENDING.
⬡ get_provider_booking_status
Consulta estado del ciclo de vida (CONFIRMED, IN_TRANSIT, BORDER_PROCESSING) y timeline de hitos con provider_event_id.
⬡ get_booking_change_options (P1)
Retorna opciones dinámicas de reprogramación o cancelación con costos y penalidades.
Código Real de Registro WebMCP Andes Freight Frontend 
// Registro en el navegador al cargar /providers/andes
document.modelContext.registerTool({
  name: "quote_freight",
  description: "Quote an international FTL freight request for Andes Freight network",
  inputSchema: {
    type: "object",
    properties: {
      freight_request_id: { type: "string" },
      origin: { type: "string" },
      destination: { type: "string" },
      cargo_weight_kg: { type: "number" }
    },
    required: ["freight_request_id", "origin", "destination", "cargo_weight_kg"]
  },
  execute: async (input) => {
    return {
      ok: true,
      data: {
        provider_offer_reference: "AND-OFF-8821",
        price: 1760.00,
        currency: "USD",
        transit_hours: 31,
        availability_class: "AVAILABLE_IN_WINDOW",
        reported_vehicle_type: "Scania R450 Heavy Semi-Trailer 18t",
        customs_coordination_included: true
      }
    };
  }
});

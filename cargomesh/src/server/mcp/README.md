# CargoMesh MCP

The active server registers capability/intake tools **and** the shared workflow catalog, including prepared/confirmed commercial actions. See [the current tool list and authentication guide](../../../../docs/API.md), [Alexa+ submission boundaries](../../../../docs/hackathon/ALEXA_PLUS.md), and [testing](../../../../docs/TESTING.md). Registration is in `server.ts`, transport in `http.ts`, and tool semantics in `src/shared/schemas/v2/mcp-workflow-catalog.ts`. Local/remote opt-ins and user identity checks remain mandatory.

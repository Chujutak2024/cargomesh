# Coordinación CargoMesh V2

## Fuentes obligatorias

Lee `../../../docs/v2-amazon/LINEAR_REBASE_PLAN.md`, `LINEAR_ISSUE_TEMPLATE.md` y `CODE_REVIEW_GUIDELINES.md`.

## Reglas de Linear

- Conserva las issues V1 canceladas como historia; no las borres, recicles ni reabras para simular avance V2.
- Crea alcance V2 en un proyecto/ciclo nuevo, con dependencias y criterios observables.
- Vincula una rama y un responsable al pasar a `In Progress`.
- Pasa a `In Review` solo con PR y evidencia verificable.
- Marca `Done` únicamente tras merge autorizado, pruebas y documentación.
- Antes de escribir en Linear, presenta el plan y confirma fechas, tracks, labels y asignaciones si aún no están acordados.

## Evidencia

Separa evidencia de producto, AWS Builder, artefacto Open Source y Friction Logs. No prometas un mini challenge ni una integración sin confirmación y artefactos verificables.
